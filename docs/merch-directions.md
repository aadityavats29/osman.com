# Merch directions — the Osman Meyredi brand shop

The shop should extend Osman's brand idea — **listening** — into objects people would
want to own even if they'd never heard of him. Not logo-on-a-T-shirt merch: objects
about listening, rhythm, space and sound, made with the same restraint as the site.

All items below are **concepts**. Nothing becomes purchasable until Osman approves it,
production is sourced, and the shop switches to `external`/`storefront` mode (Shopify).

Ranking criteria: **brand fit** (does it embody listening/rhythm/space?), **usefulness**
(would someone use it monthly?), **production complexity** (low = print-on-demand or
simple sourcing; high = custom manufacturing), **price tier** (€ = under 20, €€ = 20–60,
€€€ = 60+).

## Recommended launch set

Start with **1 + 2 + 3** (notebook, cards, score prints): all low-complexity print
production, all directly about listening, all usable in Osman's own coaching and
workshops (which markets them for free). Add **4** as the B2B bundle once corporate
workshop clients exist. Everything else waits for demand signals.

## Commerce path

Concept mode (now) → Shopify store on `shop.osmanmeyredi.com` linked in `external`
mode (DNS: CNAME `shop` → Shopify; set the URL in Studio → Site settings) → optional
Storefront API integration (`storefront` mode) if on-site browsing ever matters.
